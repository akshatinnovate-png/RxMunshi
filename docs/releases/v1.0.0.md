# RxMunshi 1.0.0: Windows and Android apps

**Released 24 November 2026**

RxMunshi now installs like any other app. Version 1.0.0 adds a Windows setup program and an Android app. Both carry the full product from v0.1.0 and work offline with no account. They open a demo pharmacy, Sharma Medical Hall in Sakchi, Jamshedpur, with made-up data, and every record stays on the device.

## Windows: install in four clicks

1. Download `RxMunshi-Setup-1.0.0.exe` and open it.
2. Windows may show **"Windows protected your PC"**, because the installer is not code-signed yet. Click **More info → Run anyway**.
3. The setup wizard walks you through: **Welcome → Licence → Components (desktop shortcut, on by default) → Install folder → Install → Finish**. Tick **Open RxMunshi now** on the last page.
4. RxMunshi appears in the **Start menu** and on the **desktop**.

- **No admin needed:** it installs for the current user in `%LOCALAPPDATA%\Programs\RxMunshi`.
- **Uninstall:** use **Settings → Apps → RxMunshi → Uninstall**, or the uninstaller in the Start menu folder. The shop's records are kept unless you delete them.
- **The Patient phone** opens in its own window, so you can stage the live YES reply with two windows side by side.
- **WhatsApp links** open in WhatsApp or the browser. **PDFs and CSVs** go through the normal Save dialog.

## Android: install the APK

1. Download `RxMunshi-1.0.0.apk` on the phone and tap it.
2. If asked, allow **Install unknown apps** for your browser or Files app.
3. Android or Play Protect may warn that the app is from an unknown developer, or was built for an older version of Android. Tap **Install anyway**. The app is signed, but it isn't on the Play Store yet.
4. Open **RxMunshi** from the app drawer.

- **Back** goes back through the screens.
- **WhatsApp reminders and orders** open straight in WhatsApp.
- **Return slips, the inspection pack and CSV exports** open Android's Save dialog, so you can pick where they go.
- **Camera** (webcam scan) and **microphone** permissions are asked for only when you use them.

## What is inside

Everything from v0.1.0, unchanged:

- **The core app:** split-screen bill scanner with the Delivery Verifier, Expiry Radar with return slip PDFs, Money-back, refills with DPDP consent and the live YES banner, Rx to H1 register, Committed-Demand Reorder, Inspector Mode with the inspection pack, and Munshi, the approval-gated agent.
- **The rest:** wholesaler scorecard, audit trail, command palette, keyboard shortcuts, jury tour, dark theme, and the clock for moving days forward.

The installed apps run the **offline Munshi planner** (Hindi, Hinglish and English), the **sample bills and prescriptions**, and the **simulated WhatsApp lane**. Live Gemini reading of bills and prescriptions, Supabase sync and the WhatsApp Cloud API still need the web version with server keys (see the README).

## How they are built

- **Shared static app:** `npm run build:static` exports the Next.js app as static files; the server routes are left out.
- **Windows:** `npm run build:windows`. Electron 44 serves the app from a private `app://rxmunshi` origin. electron-builder packages it, and a native NSIS script (`desktop/installer.nsi`) builds the setup wizard with per-user install, Start menu and desktop shortcuts, an Add/Remove Programs entry and an uninstaller.
- **Android:** `npm run build:android`. A small native Java WebView shell (`android/`) serves the bundled app from a private `https://app.rxmunshi.invalid` origin. It hands WhatsApp and other external links to their apps and saves downloads through Android's document picker. It is built with `aapt`, `javac`, `dx`, `zipalign` and `apksigner`, and signed with APK Signature Scheme v1 and v2.

## Tested

- **52 unit tests** and the web build pass.
- **Desktop app (Electron, run under a virtual display):** it opens Today, reads the sample bill (the verifier finds 9 issues), saves batches, opens the Patient phone in a second window, and keeps the data after a restart.
- **Windows installer:** a valid Windows program with RxMunshi version information. It contains the app, its icon and the uninstaller.
- **APK:** passes `apksigner verify` (v1 and v2). It contains all 96 app files and has the right package, permissions and launcher entry.

## Known limits

- **Not tested on real devices yet.** The installer was not run on Windows, and the APK was not run on a phone or emulator: this build machine has neither. Please report anything that misbehaves.
- **No code signing on Windows.** The installer is not code-signed, so SmartScreen warns on first run.
- **Older Android target.** The APK targets Android 6 (API 23). It installs and runs on current phones but can't go on the Play Store until it targets a newer API.
- **No voice on the apps.** Hindi voice input needs Chrome or Edge on the web. The desktop and Android apps don't support it, and say so when you try.
- **Demo data only.** All demo people, phone numbers and licence numbers are fictional.
